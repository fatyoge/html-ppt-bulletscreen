## Features

- **Three-role architecture** — Speaker, Moderator, and Audience with independent UIs
- **Real-time danmaku** — Instant delivery via WebSocket, DOM-based rendering
- **Slide sync** — Speaker's navigation automatically syncs to all viewers
- **Moderation** — Auto-approve mode + manual review mode, supports multiple moderators
- **Speaker controls** — Clear, pause/resume, speed and density adjustment
- **Zero build** — Pure vanilla JavaScript + CSS, no frontend build tools required
- **Deep html-ppt integration** — Auto-detects slide changes via BroadcastChannel

## Requirements

- **Node.js** >= 18.0.0
- **npm** >= 9.0.0
- An HTML presentation file (e.g., generated by html-ppt or any keyboard-navigable HTML slides)

## Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/bullet-screen.git
cd bullet-screen

# Install dependencies
npm install
```

### Launch

```bash
node server.js <path-to-your-html-file>
```

Example:

```bash
# Use the built-in test deck
node server.js examples/html-ppt-test.html

# Use your own html-ppt file
node server.js ~/my-talk/index.html
```

After launch, three URLs will be printed:

```
🎯 Danmaku server started

Speaker:   http://192.168.3.48:3000/speaker
Moderator: http://192.168.3.48:3000/moderator
Audience:  http://192.168.3.48:3000/audience
```

### Usage Flow

1. **Speaker** opens the `/speaker` link, navigates with `→` / `←` / `Space`
2. **Moderator** (optional) opens the `/moderator` link to review danmaku
3. **Audience** opens the `/audience` link to send and view danmaku

> When no moderator is online, danmaku is auto-approved. When a moderator joins, all danmaku enters a review queue.

## Role Guide

### Speaker

- Full-screen HTML slide display
- Bottom control bar: clear, pause/resume, speed/density sliders
- Slide navigation auto-syncs to all audience and moderator clients

### Audience

- Full-screen HTML slide display
- Collapsible right sidebar: text input + 8-color picker
- Sent danmaku appears after review (when moderator is present)

### Moderator

- Full-screen HTML slide display
- Collapsible right sidebar: pending danmaku queue
- Approve or block each danmaku individually
- Multiple moderators can work simultaneously with a shared queue

## html-ppt Integration

This project deeply integrates with [html-ppt-skill](https://github.com/lewislulu/html-ppt-skill):

- **BroadcastChannel monitoring** — Auto-captures presenter mode slide changes
- **Keyboard fallback** — Automatically falls back to keyboard event interception when BroadcastChannel is unavailable
- **Animation sync** — Re-triggers html-ppt CSS entry animations on viewer side
- **Presenter Mode compatible** — Pressing `S` to open presenter window doesn't break danmaku sync

Supported html-ppt shortcuts:

| Key | Function |
|-----|----------|
| `← →` / `Space` | Navigate slides |
| `T` | Cycle themes |
| `F` | Fullscreen |
| `S` | Presenter mode |
| `O` | Slide overview |

## Protocol

Server and client communicate via Socket.IO. Key events:

### Client → Server

| Event | Sender | Description |
|-------|--------|-------------|
| `danmaku:send` | audience | Send a danmaku |
| `danmaku:block` | moderator | Block a danmaku |
| `slide:go` | speaker | Navigate slides |
| `control:*` | speaker | Control commands |

### Server → Client

| Event | Target | Description |
|-------|--------|-------------|
| `danmaku:approved` | all | Danmaku approved |
| `danmaku:blocked` | all | Danmaku blocked |
| `slide:go` | audience/moderator | Slide sync |
| `slide:sync` | new connection | Current slide position |

See full protocol in [`docs/superpowers/specs/2026-05-24-bullet-screen-design.md`](docs/superpowers/specs/2026-05-24-bullet-screen-design.md).
